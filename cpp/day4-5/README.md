## 构造函数进阶与对象生命周期

1. 拷贝构造函数
一种特殊的构造函数，作用是：用一个已存在的对象，“复制” 出一个新的同类型对象

常用于：

- 通过使用另一个同类型的对象来初始化新创建的对象
用一个对象初始化新对象（比如Line line2 = line1）

- 复制对象把它作为参数传递给函数
对象以传值方式作为函数参数（比如display(line)里的obj）

- 复制对象，并从函数返回这个对象
对象以传值方式作为函数返回值

如果我们不自己写拷贝构造函数，编译器会自动生成一个默认拷贝构造函数—— 但默认的是 “浅拷贝”：
- 浅拷贝：新对象的ptr会直接指向原对象ptr的内存地址（两个对象共用同一块内存）；
- 后果：当两个对象析构时，会重复释放同一块内存，导致程序崩溃；
- 给新对象的ptr分配独立的内存，再拷贝原对象的值  这样两个对象的ptr各有自己的内存，析构时各自释放自己的，不会出错。

2. 友员
分为友元函数和友元类，在类里面声明，在类外定义，可以使用类里的公有和私有内容。

注意：友元关系是 “单向的”
