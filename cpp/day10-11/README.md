# 虚函数与多态

对于我来说，理解东西我先是看看这个东西的作用是什么，理解他的意义以后，我才能更好的结合相应的场景去使用他

## 虚函数
- 虚函数的作用就是 “让函数调用跟着「指针实际指向的对象」走，而不是跟着「指针的类型」走”。
简单说就是：用同一个接口（比如display），不同的对象调用时自动执行不同的逻辑，不用写一堆类型判断。

- 注意override关键字

## 虚析构函数

当通过基类指针删除派生类对象时，如果基类的析构函数不是虚函数，则只会调用基类的析构函数，而不会调用派生类的析构函数，这可能导致内存泄漏。

因此，当类可能作为基类时，应当将其析构函数声明为虚函数：

```cpp
#include <iostream>
using namespace std;

class Base {
public:
    Base() {
        std::cout << "Base constructor" << std::endl;
    }

    virtual ~Base() {
        std::cout << "Base destructor" << std::endl;
    }
};

class Derived : public Base {
public:
    Derived() {
        std::cout << "Derived constructor" << std::endl;
    }

    ~Derived() override {
        std::cout << "Derived destructor" << std::endl;
    }
};

int main() {
    Base* ptr = new Derived();
    delete ptr; // 会正确调用Derived和Base的析构函数
    return 0;
}
```
## 纯虚函数和抽象类

- 纯虚函数是一个在基类中声明但没有实现的虚函数，语法是在函数声明后加上= 0：
`virtual return_type function_name(parameters) = 0;`

- 包含至少一个纯虚函数的类被称为抽象类：
	1. 不能直接实例化对象（比如 Base obj; 会直接报错），只能作为基类被继承。
	2. 派生类必须实现所有纯虚函数，否则它也是抽象类
	3. 可以用来定义接口

- 纯虚函数和虚函数的区别：
	1. 本质是 “是否有默认实现”“是否强制派生类重写”，作用也从 “灵活多态” 变成了 “定义接口标准”。
	2. 纯虚函数的价值，是强制所有派生类都遵守同一个 “接口标准”—— 基类只规定 “必须做什么”，但不规定 “具体怎么做”，具体实现交给派生类。

| 对比项               | 虚函数                                 | 纯虚函数                               |
|----------------------|----------------------------------------|----------------------------------------|
| 写法                 | `virtual void func() { 有默认实现 }`   | `virtual void func() = 0;`（无实现）|
| 派生类是否必须重写   | 可选（可以不重写，直接用基类的默认实现） | 必须（否则派生类也会变成抽象类，不能实例化） |
| 基类能否创建对象     | 可以（基类是普通类）| 不能（基类是抽象类）|
| 核心作用             | 运行时多态，提供“可选重写”的默认逻辑   | 定义接口规范，强制派生类实现统一的功能 |
