## 继承机制与派生类

1. 在正式学习前系统回顾指针和类的知识
- 指向常量的指针：不能通过ptr修改value的值
const int *ptr= &value
- 常量指针：不能改变ptr指向的地址
int *const ptr = &value
- 动态内存分配
单个的动态分配：int *ptr= new int；
数组的动态分配：int *ptr= new int[n]；
new分配后，别忘记用delete来释放内存
动态分配的数组必须使用delete[]释放，而不是delete
- 实践注意：
总是初始化指针，优先使用nullptr来
区分清楚指针和他指向的数据，记住*是在解引用 
- 指针直接比较
比较的是位置的前后，要比较指向的内容，要解引用
- 分清楚数组指针与指针数组
int* array[5];    // 指针数组：包含5个int指针的数组
int (*array)[5];  // 数组指针：指向包含5个int元素的数组的指针

2. 继承类型
当一个类派生自基类，该基类可以被继承为 public、protected 或 private 几种类型。继承类型是通过上面讲解的访问修饰符 access-specifier 来指定的。

几乎不使用 protected 或 private 继承，通常使用 public 继承。当使用不同类型的继承时，遵循以下几个规则：

- 公有继承（public）：
当一个类派生自公有基类时，基类的公有成员也是派生类的公有成员，基类的保护成员也是派生类的保护成员，基类的私有成员不能直接被派生类访问，但是可以通过调用基类的公有和保护成员来访问。

- 保护继承（protected）： 
当一个类派生自保护基类时，基类的公有和保护成员将成为派生类的保护成员。

- 私有继承（private）：
当一个类派生自私有基类时，基类的公有和保护成员将成为派生类的私有成员。
- 基类的 3 种成员权限
 public：基类内部、派生类、外部都能访问；
 protected：基类内部、派生类能访问，外部不能；
 private：只有基类内部能访问，派生类、外部都不能。

| 基类成员的权限 | public继承后派生类中权限       | protected继承后派生类中权限   | private继承后派生类中权限     |
|----------------|--------------------------------|-------------------------------|-------------------------------|
| public         | public（派生类/外部能用）      | protected（派生类能用，外部不能） | private（只有派生类内部能用，派生类的派生类不能用） |
| protected      | protected（派生类能用）        | protected（派生类能用）       | private（派生类内部能用）     |
| private        | 不能直接访问（任何继承都拿不到） | 不能直接访问                  | 不能直接访问                  |

- 简单总结三种继承的核心区别：
public继承：最常用！保持基类的 “对外公开” 特性（子类对象能直接用基类的 public 成员）；
protected继承：基类的 public 成员会变成子类的 protected（子类对象不能直接用，只有子类内部能用）；
private继承：基类的 public/protected 成员都会变成子类的 private（只有子类内部能用，子类的子类也拿不到）。

单纯论使用来说，public继承后，派生类就是一个可以使用基类和自己本身内容的东西

- 继承时，基类和派生类的构造、析构函数执行顺序是固定的：
构造函数：先执行基类的构造，再执行派生类的构造；
析构函数：先执行派生类的析构，再执行基类的析构。
