# 学生系统项目

## 1. 项目要实现的结果
本项目是一个**轻量的学生信息管理系统**，最终实现以下功能：
- 手动添加学生信息（包含姓名、学号、成绩）；
- 批量展示所有学生的完整信息；
- 将学生数据持久化到本地文件（`data.txt`），避免程序退出后数据丢失；
- 从本地文件加载已保存的学生数据；
- 按学生姓名搜索并展示匹配的信息。


## 2. 项目实现的方法
项目采用**“封装+模块化”**的C++编程思路，核心实现方式如下：
1. **数据封装：`Student`类**
   - 用私有成员存储学生的姓名、学号、成绩，通过公有方法（`display`/`saveToFile`等）操作数据，保证封装性；
   - 提供`getter`方法对外暴露只读数据，避免直接修改成员的风险。

2. **集合管理：`StudentManager`类**
   - 用`vector<Student>`存储学生集合，利用`vector`的动态扩容特性管理任意数量的学生；
   - 封装“添加、展示、文件读写、搜索”等批量操作，将业务逻辑与数据分离。

3. **文件持久化：C++文件流**
   - 用`ofstream`（写文件）和`ifstream`（读文件）实现数据的持久化；
   - 存文件时先写学生总数、再逐个存信息；读文件时先读总数、再循环加载，保证数据的完整性。


## 3. 感悟
1. **模块化编程的优势**：将“单个学生”和“学生管理”拆分为两个类，代码职责清晰，后续想扩展功能（比如修改成绩、删除学生）时，只需在对应类中添加方法，不影响其他模块；
2. **封装的意义**：`Student`类隐藏了数据细节，对外只提供必要的操作接口，既避免了误修改数据，也让调用方更易用；
3. **文件操作的细节**：第一次写`loadFromFile`时容易忽略`ifs.ignore()`，导致后续`getline`读空行——这让我意识到文件流操作要注意缓冲区的残留字符，细节决定程序的稳定性；
4. **持久化的必要性**：如果没有文件读写功能，程序退出后数据就会丢失，这让我理解了“数据持久化是实用程序的基础能力”。
