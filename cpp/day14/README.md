# C++ 友元与运算符重载

## 一、友元（Friend）
### 1.1 友元的定义
类的友元函数是**定义在类外部**，但有权访问类的所有**私有（private）** 成员和**保护（protected）** 成员的特殊函数。

### 1.2 核心要点
- 关键字：`friend`（声明友元时必须使用）
- 重要特性：友元函数**不是**类的成员函数，仅拥有对类内部成员的访问权
- 使用建议：友元会破坏类的封装性（面向对象的核心特性），除非必要场景，建议慎用

## 二、运算符重载
### 2.1 重载的意义
运算符重载主要用于**自定义类型（如自定义类/结构体）** 的运算，核心目标是让自定义类型能够像内置类型（int、float等）一样使用运算符，简化代码逻辑。

### 2.2 核心语法
重载运算符的核心是关键字 `operator`，格式为：
```cpp
返回值类型 operator 运算符(参数列表) {
    // 自定义运算逻辑
}
```
### 2.3 可重载 / 不可重载运算符清单
#### 🔹 可重载的运算符
| 分类               | 运算符列表                                                     |
|--------------------|----------------------------------------------------------------|
| 双目算术运算符     | + (加)、- (减)、* (乘)、/ (除)、% (取模)                      |
| 关系运算符         | == (等于)、!= (不等于)、< (小于)、> (大于)、<= (小于等于)、>= (大于等于) |
| 逻辑运算符         | \|\| (逻辑或)、&& (逻辑与)、! (逻辑非)                         |
| 单目运算符         | + (正)、- (负)、* (指针)、& (取地址)                          |
| 自增自减运算符     | ++ (自增)、-- (自减)                                           |
| 位运算符           | \| (按位或)、& (按位与)、~ (按位取反)、^ (按位异或)、<< (左移)、>> (右移) |
| 赋值运算符         | =、+=、-=、*=、/=、%=、&=、\|=、^=、<<=、>>=                   |
| 空间申请与释放     | new、delete、new[]、delete[]                                  |
| 其他运算符         | () (函数调用)、-> (成员访问)、, (逗号)、[] (下标)              |

#### 🔸 不可重载的运算符
| 运算符       | 名称                 | 备注                     |
|--------------|----------------------|--------------------------|
| `.`          | 成员访问运算符       | 保障类的封装性           |
| `.*`/`->*`   | 成员指针访问运算符   | 核心底层运算符           |
| `::`         | 域运算符             | 命名空间 / 类域标识      |
| `sizeof`     | 长度运算符           | 编译期确定的内置运算     |
| `?:`         | 条件运算符           | 三目运算符，语法特殊性   |
| `#`          | 预处理符号           | 编译预处理阶段生效       |
