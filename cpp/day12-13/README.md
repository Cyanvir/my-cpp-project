#  抽象类与接口设计

## 知识回顾
1. this 指针
	[代码酷](https://www.echo.cool/docs/language/cpp/cpp-object-oriented-basics/cppthis-pointer)
	eg.`fluent_interface.cpp`实现流式接口

	1. 用法 1：区分同名的成员变量与函数参数 / 局部变量
	```cpp
	类名::成员函数名(参数类型 同名参数) {
    this->成员变量名 = 同名参数; // this->区分成员变量与参数
	}
	class Rectangle {
	private:
		double length;
	public:
		Rectangle(double length) {
			this->length = length; // 左边是成员变量，右边是参数
			}
	};
	```
	2. 返回当前对象（实现链式调用）
	成员函数返回*this（当前对象的引用），使多个成员函数可以连续调用（全程操作同一个对象）。
	```cpp
	类名& 类名::成员函数名(参数列表) {
    // 函数逻辑
    return *this; // 返回当前对象的引用（返回类型必须是“类名&”）
	}
	class Counter {
	private:
		int count;
	public:
		Counter& increment() {
			count++;
			return *this;
		}
	};// 链式调用：counter.increment().add(5);
	```
	3. 将当前对象作为参数传递给其他函数
	```cpp
	class Person {
	public:
		string name;
		void passSelf() {
			printName(this); // 传递当前对象的地址
		}
	};
	void printName(Person* p) {
		cout << p->name << endl;
	}
	```
	4. 显式访问当前对象的其他成员函数
	```cpp
	class Student {
	public:
		void study() { cout << "学习中" << endl; }
		void startDay() {
			this->study(); // 显式调用study()
		}
	};
	```
	5. this指针与const成员函数
	在const成员函数中，`this`指针的类型是`const Class* const`，这意味着不能修改对象的成员变量

	6. **注意：**
	**避免在静态成员函数中使用this指针，因为静态成员函数不属于特定对象。当返回*this时，最好返回引用而不是值，以避免不必要的对象复制。**
## 新知
1. 抽象类
	1. 核心特点
	- 包含至少一个纯虚函数：使用 virtual 关键字声明，并在函数声明结尾添加 = 0
	- 不能创建抽象类的对象：抽象类是不完整的，需要派生类来完成其功能
	- 可以有指向抽象类的指针和引用：这些指针和引用可以指向抽象类的派生类对象
	- 可以包含数据成员和普通成员函数：抽象类除了纯虚函数外，还可以拥有普通的成员
	2. 接口
	**在C++中通常将只包含纯虚函数的抽象类称为"接口类"，它定义了一组必须实现的方法，但不提供具体实现。**
	- 框架设计与插件系统
		抽象类非常适合用于设计插件系统或框架，其中基类定义接口，而具体功能由插件或模块实现
	| 特性               | 抽象类                                 | 普通类                               |
	|----------------------|--------------------------------------|-------------------------------------|
	| 实例化                | 不能直接实例化   | 可以直接实例化|
	| 纯虚函数  | 至少包含一个 | 没有或可选 |
	| 用途| 定义接口，通过部分实现| 提供完整实现|
	| 派生类要求| 必须实现所有纯虚函数  | 可以直接使用基类功能|
	3. **注意：**
	**在使用抽象类时，一定要记得提供虚析构函数，以确保当通过基类指针删除派生类对象时能够正确调用派生类的析构函数。**
2. 接口类(特殊的抽象类)
	- 只包含纯虚函数（没有实现的虚函数）
	- 不包含数据成员
	- 不提供任何实现
	- 作为子类必须实现的契约或规范
	**任何继承接口的类必须实现接口中定义的所有纯虚函数，否则该类也会变成抽象类。**
	1. 特性
	- 纯虚构函数
	- 多继承
	- 默认实现
